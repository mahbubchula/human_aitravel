# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [1.0.0] - 2026-01-15

### Added
- 🎬 Cinematic 5-scene scroll-driven visual experience
- 🖼️ AI-generated background imagery (5 unique scenes)
- ✨ Film grain overlay and letterbox effects for video-style presentation
- 📊 Animated progress bars showing cognitive load visualization
- 🤖 Interactive Human-AI collaboration conversation flow
- 📈 Side-by-side comparison: Traditional vs AI-assisted travel planning
- 🎯 Scroll-triggered reveal animations with IntersectionObserver
- 🌊 Ken Burns effect on background images
- 💫 Floating data stream particles
- 📍 Navigation dots with active section tracking
- 📱 Fully responsive design (mobile, tablet, desktop)
- 🎨 Custom CSS animations (float, pulse, typing, particle effects)
- ⚡ Optimized build with Vite 6
