## ✨ Overview

This project is an immersive, scroll-driven visual narrative that tells the story of how **Human-AI collaboration** transforms travel decision-making from an overwhelming 60+ hour process into a seamless 15-minute experience.

Built with cinematic effects, AI-generated imagery, and smooth animations, it presents a compelling case for the future of collaborative intelligence.

## 🎬 Experience Scenes

| Scene | Title | Description |
|-------|-------|-------------|
| 1 | **Opening** | Cinematic hero with floating data streams and dramatic typography |
| 2 | **The Decision Paradox** | Visualizing human cognitive overload with animated progress bars |
| 3 | **AI Decision Matrix** | Showcasing AI capabilities with scroll-triggered card animations |
| 4 | **The Perfect Synergy** | Step-by-step Human-AI conversation flow |
| 5 | **The Journey Begins** | Side-by-side comparison of traditional vs AI-assisted planning |

## 🚀 Getting Started

### Prerequisites

- **Node.js** >= 18.x
- **npm** >= 9.x

### Installation

```bash
# Clone the repository
git clone https://github.com/your-username/human_aitravel.git

# Navigate to the project
cd human_aitravel

# Install dependencies
npm install
```

### Development

```bash
# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build

```bash
# Build for production
npm run build

# Preview production build
npm run preview
```

### Type Check

```bash
npm run typecheck
```

## 🎨 Visual Features

- **Film Grain Overlay** — Subtle texture for cinematic feel
- **Letterbox Bars** — Widescreen movie-style framing
- **Ken Burns Effect** — Slow zoom/pan on background images
- **Scroll-Triggered Animations** — Elements reveal as you scroll
- **Data Stream Particles** — Floating animated data visualization
- **Gradient Borders** — Animated hue-rotating borders
- **Vignette Effect** — Dark edges for depth
- **Progress Bar** — Top-of-page scroll indicator
- **Navigation Dots** — Side navigation with active state
